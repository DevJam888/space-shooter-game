# Space Frontier: 8-Bit Shooter

A simple retro-style 8-bit shooter game built with Phaser 3, featuring classic pixel art graphics and straightforward gameplay.

## 🎮 Game Features

- Classic 8-bit pixel art graphics
- Simple arrow key movement
- Spacebar shooting
- Basic enemy types
- Progressive difficulty

## 🛠️ Technical Stack

- Phaser 3 for game engine
- JavaScript for game logic
- HTML5 for game container

## 📁 Project Structure

```
/
├── assets/           # Game assets
│   └── SpaceShooterAssets/  # Game asset pack
│       ├── Characters.png
│       ├── Ships.png
│       ├── Projectiles.png
│       ├── BackGrounds.png
│       ├── Miscellaneous.png
│       └── IU.png
├── index.html       # Main HTML file

└── README.md       # Project documentation
```

## 🚀 Getting Started

1. Clone the repository
2. Open `index.html` in your web browser
3. Start playing!

## 🎯 Game Controls

- **Arrow Keys**: Move the spaceship
- **Spacebar**: Shoot
- **ESC**: Pause game

## 🎨 Game Elements

### Player

- Simple spaceship that moves with arrow keys
- Basic shooting with spacebar
- Lives system

### Enemies

- Basic enemy ships that move in simple patterns
- Appear from the top of the screen
- Take one hit to destroy

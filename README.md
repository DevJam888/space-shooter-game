# Space Frontier: 8-Bit Shooter

A retro-style 8-bit space shooter game built with Phaser 3, featuring classic pixel art graphics and straightforward gameplay.

🎮 [Play the Game](https://devjam888.github.io/space-shooter-game/)

![Game Screenshot](assets/SpaceShooterAssets/screenshot.png)

## 🚀 Features

- Classic 8-bit pixel art graphics
- Simple arrow key movement
- Spacebar shooting
- Enemy ships with basic AI
- Explosion effects
- Progressive difficulty
- Instant restart option

## 🎯 How to Play

1. Use **Arrow Keys** to move your spaceship
2. Press **Spacebar** to shoot
3. Destroy enemy ships
4. Avoid colliding with enemies
5. Press **ESC** to pause
6. Press **Spacebar** to restart when game over

## 🛠️ Local Development

### Prerequisites

- A modern web browser
- A local web server (Python's SimpleHTTPServer, Live Server, etc.)

### Running Locally

1. Clone the repository:

```bash
git clone https://github.com/DevJam888/space-shooter-game.git
cd space-shooter-game
```

2. Start a local server:

```bash
# Using Python 3
python -m http.server 8000
```

3. Open your browser and navigate to:

```
http://localhost:8000
```
